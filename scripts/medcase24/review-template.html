Verbatim source partitions for a fully connected, three-round case conference. Complexity labels reflect evidence integration, not measured model difficulty. Source units and word counts are not atomic-fact counts.

Selection and experiment boundaries

Screened the official training split for longer prompts with laboratory, imaging and numeric evidence. Reviewed 140 candidates in a fixed hash order within broad keyword strata; selected four cases in each of six manually reviewed clinical strata. This is a purposive feasibility cohort, not a representative clinical sample.

All five conditions use the same complete source text. Split conditions give each source unit to exactly one agent; shared conditions give all units to all agents. Clinical, imaging and laboratory/pathology are source-oriented roles, not separate organ departments. Source seats are balanced across A/B/C. Mismatching rotates only role prompts, with no correctly matched seat.

Mixed sentences retain their original context and go to one primary source category. They are marked below; boundaries do not imply perfectly isolated modalities. References and these review notes never enter agent prompts. Some reference labels are more specific than the visible evidence supports; accuracy remains ungraded pending a separate semantic scoring protocol.
