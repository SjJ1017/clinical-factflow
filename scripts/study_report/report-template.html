Reading the experiment

Shared / generic and shared / specialist expose every agent to the same case material. Split conditions distribute clinical, laboratory/pathology and imaging material. Mismatching rotates specialist prompts across those partitions. Roles are aligned by profession across cases; A/B/C seats are counterbalanced.

The report distinguishes naming accuracy, output composition and selective uptake. A fact visible in an input and repeated in an output supports a transmission opportunity; it does not establish which source caused the output.
01 · Outcome

Accuracy across all three rounds

Same paired cases in every condition. Agent accuracy averages three agents within each case; system accuracy uses one panel prediction per case.

Why the curves cluster near 50%

This is open-ended diagnosis: 50% is not a chance baseline. The default credits same-specificity synonyms only (S). L is a definite taxonomic difference; U needs case-supported adjudication. Three rounds do not establish a performance ceiling. One system case changes accuracy by 4.17 percentage points.

06 · Alignment

Does mismatch follow information or the specialist role?

For every mismatched agent, compare two agents from the matched split-specialist run of the same case: the agent with the same initial information (same seat), and the agent with the same prompted profession (a different seat).

Primary state measure: eight-label output composition, with total-variation distance (0 = identical, 1 = disjoint). Each comparison uses the fact unit and label weighting selected in section 03. Positive distance difference means closer to the information-aligned agent; negative means closer to the role-aligned agent. This compares observable output states, not a causal contribution from information versus prompts.

Exact atomic-content sensitivity check

Jaccard distance between sets of case-local exact text + qualifier atom IDs. No cross-run semantic merging is inferred from trace-local NLI pairs. This check ignores wording-equivalent atoms and is therefore a lexical-content sensitivity measure, not semantic equivalence. It is independent of label weighting and fact grouping.

Methods & reproducibility

Definitions, uncertainty and audit

Conditions and role alignment. Generic/split agents inherit their information partition's profession. Generic/shared agents inherit the corresponding matched-specialist seat assignment for that same case. Mismatched agents retain their actual prompted profession. No position is relabeled after observing performance.

Multi-label units. Repeated exact atoms within an input/output set count once. With equivalence grouping, the unit's labels are the union of its member atoms' saved occurrence labels in that set. For inclusive weighting, own = any own-profession label and other = any other-profession label. For fractional weighting, own/other are the corresponding label counts divided by all labels, including shared labels.

Output metrics. Own share = own weighted output units / all output units. Other share uses all other professions pooled. Output prime = own share − other share. Input own share uses the same calculation on the visible input union.

Uptake. Own rate = retained own weighted input units / own weighted input units. Other rate uses other-profession weighted input units. Uptake prime = own rate − other rate. Direct entailment mode only accepts input ⇒ output, never the reverse direction. No unseen intermediate atom supplies a match.

Aggregation. Ratios are computed per agent/case first. Each profession has one agent per case, so profession curves average 24 values where defined. All-profession contrasts first average within each case. Percentile bootstrap intervals use 2,000 paired-case resamples and a fixed seed. Missing denominators are reported through n. Intervals are exploratory and not adjusted for multiple comparisons.

Interpretation. This is a selected 24-case feasibility cohort. Information split changes what is available, so a higher output share alone need not indicate a stronger preference. Own/other uptake rates condition on availability, and the output-minus-input share view provides a second reference. Changes in matching components are not necessarily changes in independent clinical information.

Accuracy limits. Exact is a naming baseline. Fuzzy same-disease and taxonomic-level compatibility use MiniMax M3 with thinking disabled, followed by explicit name-level corrections. Cause/complication relationships needing patient context remain unresolved. No correctness labels enter voting or generation. A nontransitive synonym vote abstains instead of selecting an arbitrary clique.

Sources. MedCaseReasoning · OpenCode Go prices. Original traces, atom labels, NLI values and blocker UNRELATED decisions remain unchanged. Analysis is offline except the audited short-name judging calls.
