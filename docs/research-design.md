# 研究设计：为什么分信息，以及什么结论能成立

## 核心定位

研究对象应是**证据分散、上下文与通信有成本的专业协作系统**。不必证明 LLM 完全不懂另一学科，才能研究分布式证据：具体患者这次的检验值、企业这年的口径调整、某合同的例外条款不是通用知识。然而，若全部信息很短、可合法便宜地集中处理且单模型可靠解决，分信息版本只能是通信约束下的压力测试，不能声称部署多 agent 更合理。

同一个基础模型套三个专业提示，是 role prompting，不是三套真实不同的知识。现实医生的专业边界也不等于完全听不懂他人报告。若要研究“理解壁垒”，应测量每位 agent 对各证据域的独立理解准确率；必要时使用已有专业模型、不同检索库或工具权限，并证明差异。当前骨架没有模拟或验证这种能力异质性。

## 三个分开的自变量

| 维度 | 改变什么 | 保持什么 |
|---|---|---|
| Topology | 消息可达关系 | 角色／任务提示、源分配、轮次、时序、记忆、模型、cohort |
| Role prompts | 各 agent 的工作职责提示 | 源分配、拓扑、模型、输出预算 |
| Information | 哪些原始报告最初由谁持有 | 系统合计证据相同，不按 gold 筛证据，角色／任务提示不变 |

同步 full／star／chain 是主拓扑对照。轮内串行 chain 改了时序，是另一个实验维度，不能把它和同步 full 的差异全部归为拓扑。hub／链位置应轮换，防止把中心性或先后顺序当作角色效果。先固定 `self_memory=all, peer_memory=last, evidence_visibility=every_round`，再单独做去源文本或记忆消融。

原项目 `fix.md` 中“私有证据使出现只可能来自传输”的表述也需收窄：模型可能独立推导或猜中。分信息让具体未知值的流向更可识别，但真正的传递因果仍要干预验证。

## 必须保留的对照

1. **Solo＋全部证据**：先验证信息充分性与任务是否已经饱和。若失败，不能把多 agent 的同类失败全归为通信。
2. **同一 panel＋共享全部证据**：保持角色和计算量，隔离初始信息分布的影响。
3. **无专业提示＋相同信息分区**：测角色提示是否有额外作用。
4. **相同角色＋无通信**：测信息交换相对独立求解的贡献；当前 `topology: none` 可表示。
5. **预算匹配对照**：既按固定轮次比较，也按总输入／输出 token 或墙钟预算比较。单轮 solo 是充分性基线，不是和九次调用 compute-matched。

专业分区不应和角色身份绑定死。例如同样的三份报告，在 generalist 条件仍按同样方式发放；改变角色提示不能自动把 A 的证据变成另一份。另设角色与证据错位／轮换条件时，将它作为明示干预。

## Fact profile 与错误归因

第一步是描述／预测：在哪一轮、哪位 agent 的 profile 可以预测最终失败？可以考虑观察／推断比例、否定信息保留、数值与条件保留、可见证据的表达比例、源／同伴事实的相对使用，以及不确定性变化。按病例划分训练／测试，同病例的多拓扑／多角色／多轮记录不得跨集合。疾病类型、文本长度、模型和任务难度可能同时影响 profile 与失败，需要独立控制。

“profile 能预测失败”仍不等于“profile 导致失败”。关键因果实验是用**原本存在且正确的证据**进行定向投递或恢复，再观察是否纠错，例如：

- 报告从未进入终局 agent 的 context：在固定节点／轮次补充原报告，测 transport bottleneck。
- 已经进入 context，但相关事实未表达：引导检查已可见证据，测选择／注意瓶颈。
- 数值表达了，但单位、时间或适用范围丢失：恢复原限定条件，测表示损失。
- 正确事实和条件都到达，最终判断仍错：考虑整合／规则运用或任务 evaluator 的问题。

在干预前，应人工确认“缺失的事实”并非抽取器漏掉、“两条不同事实”并非原子化不一致、“失真”并非参考标注不完备。新的 matcher 阈值 5.28 是历史默认，不是支持这些医学判断的验证证据。

## 收益与测量边界

最终应同时报告任务质量、调用成功率、token／延迟和关键事实表现。更多 entailment、更多改口、更高 overlap 均不能直接当作更好或更坏。NLI 的逻辑蕴含也不验证医学真实性。当前只保存原始测量所需记录，没有添加分析／分类器／因果脚本，避免在研究命题未定前维护一次性代码。
